## ▶️ Run the Project

Create virtual environment

```bash
python -m venv venv
```

Activate virtual environment

### Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run FastAPI

```bash
uvicorn student_api:app --reload
```

Open Swagger

```
http://127.0.0.1:8000/docs
```
